プライバシーポリシー

「競馬動画の投稿」（以下、このツール）は、運営者が自分の YouTube チャンネルに動画を投稿するためだけに使う個人用のツールです。

取得する情報

このツールは、運営者が許可した Google アカウントについて、YouTube Data API の権限（https://www.googleapis.com/auth/youtube）を使います。使う範囲は、運営者のチャンネルへの動画のアップロード、サムネイルの設定、再生リストへの追加、公開状態と公開予約の変更・確認だけです。

情報の扱い

認証のトークンは運営者のパソコンの中だけに保存し、第三者に渡したり、ほかの目的に使ったりしません。運営者以外の方の情報は取得しません。

このツールによる Google ユーザーデータの使用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

許可の取り消し

許可は、Google アカウントのサードパーティ アクセスの設定からいつでも取り消せます。
